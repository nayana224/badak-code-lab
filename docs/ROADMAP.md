# 학습 확장 계획

현재 실행할 수 있는 수업은 [전체 학습 목차](../CURRICULUM.md)에 있습니다. 아래는 전체 분야를 살펴본 뒤 정리한 다음 단계이며, 계획 항목은 아직 구현된 수업이 아닙니다. 각 분야는 여기 적은 항목으로 완결되지 않습니다.

## Python

현재 변수·함수·클래스, 참조와 얕은 복사, 컴프리헨션, 제너레이터·반복자, 메모리 기반 컨텍스트 관리자, 타입 힌트, 기본 테스트, 작은 자동 미분기와 기초 자료구조를 다룹니다.

다음에는 모듈과 패키지, 가상 환경, 파일과 경로, 파일 기반 컨텍스트 관리자, 반복자 프로토콜 심화, 타입 검사 도구와 테스트·디버깅을 추가합니다. 자료구조는 딕셔너리·집합 활용, 트리·그래프와 복잡도 분석이 필요합니다. 브라우저 실행 환경에서 파일과 패키지 관련 기능이 어디까지 가능한지 확인하고 한계를 수업에 표시합니다.

## 모던 C++

현재 C++20까지의 기초, 템플릿과 concepts, RAII, 복사·이동, 스마트 포인터, ranges·span·string_view, variant, unordered_map, 캡처 수명, 값 범주, 규칙 0과 예외 발생 시 상태 보존을 다룹니다. 일부는 입문 수준입니다.

다음에는 포인터와 참조·const의 체계적인 복습, 함수 오버로드와 값 범주, 이동과 완벽 전달, 규칙 0/5, 템플릿과 concepts 응용, 반복자와 컨테이너 무효화, ranges의 소유권·지연 평가, 예외 안전성, 테스트와 CMake를 단계적으로 보강합니다. 이후 스레드·동기화, 코루틴과 모듈은 실행 환경 및 컴파일러 지원을 확인한 후 다룹니다. C++23은 현재 C++20 실행 환경과 구분합니다.

## PyTorch와 수학

현재 텐서·shape, 기울기, 작은 학습 루프, 모델과 데이터 분리, `nn.Module`, 배치별 학습과 분류 손실, 메모리 기반 state_dict 복원, 기초 Attention과 인과 마스크를 다룹니다.

다음에는 NumPy 축·브로드캐스팅과 수치 미분 비교, 데이터 전처리·실제 데이터셋을 이용한 배치 학습, 분류 지표와 데이터 누수, 파일 기반 체크포인트와 optimizer 상태 복원, 재현성, 디바이스·dtype, GPU 실행의 차이, 자동 미분의 그래프 수명과 메모리를 단계적으로 다룹니다. GPU 실습은 현재 CPU 전용 실행 환경과 구분합니다.

## Attention과 Transformer

현재 내적, 안정적인 softmax, Q·K·V 가중합, 인과 마스크를 작은 텐서로 계산하고 실제 기록을 시각화합니다. 투영 없이 이미 나뉜 Q·K·V로 다중 헤드의 계산과 결합도 살펴봅니다. 학습 가능한 투영, 위치 정보, 잔차 연결과 정규화를 하나씩 익힌 뒤 작은 Transformer 블록을 만들고, 작은 텍스트 데이터로 학습·평가하며 제공 구현과 비교하는 실습은 향후 계획입니다.

## 학습 경험

모든 현재 수업에는 확인 문제와 설명 예시가 있습니다. 점진적으로 더 많은 문제에 다양한 입력 검사와 구현 과제를 추가하고, 트리·그래프와 모델의 실제 실행값에 맞춘 시각화를 보강합니다. 현재 C++의 많은 실습은 출력 기준 검사이므로 전체 정확성 보장을 뜻하지 않습니다.

# 문제 해결

## 사이트에 연결할 수 없어요

1. 터미널에서 프로젝트 폴더로 이동해 `python3 server.py`를 실행합니다. Windows에서는 `py -3 server.py`도 사용할 수 있습니다.
2. `바닥부터 실습실: http://127.0.0.1:8000`이 표시되면 **서버를 실행한 같은 컴퓨터**에서 해당 주소를 엽니다. 서버 터미널을 닫거나 컴퓨터를 재시작하면 다시 실행해야 합니다.
3. `Address already in use`가 나오면 `python3 server.py --port 8001`로 실행하고 `http://127.0.0.1:8001`을 엽니다. Windows에서는 `py -3 server.py --port 8001`을 사용하세요.
4. 다른 포트나 브라우저를 사용하면 기존 진도와 입력 코드가 보이지 않을 수 있습니다. 데이터는 브라우저와 주소·포트별로 저장됩니다.

서버가 실행되고 있는 터미널의 메시지를 확인하세요. Python 자체를 찾을 수 없다면 Python 3.10 이상을 설치한 후 새 터미널을 열어 다시 시도합니다.

## Python 또는 NumPy 실행이 준비되지 않아요

브라우저에서 Pyodide 실행 환경과 NumPy를 처음 내려받을 때 인터넷이 필요합니다. 연결이나 CDN 접근이 차단되어 있으면 실패할 수 있습니다. 인터넷 연결을 확인하고 새로고침해 다시 실행하세요.

## C++ 또는 PyTorch가 실행되지 않아요

사이트 상단의 **실행 환경**에서 상태를 확인하고 필요한 환경을 준비하세요. Docker가 설치되어 있지만 꺼져 있으면 **Docker 시작**을 누를 수 있습니다. 자동 시작은 지원되는 Docker Desktop 설치에서만 동작하며 시스템 관리자 권한을 자동으로 얻지 않습니다. 설치되어 있지 않거나 자동 시작이 실패하면 화면의 안내에 따라 Docker Desktop을 직접 실행하거나 Docker Engine 및 현재 사용자의 권한을 확인하세요.

이미지를 준비할 때 인터넷과 시간이 필요합니다. 진행 내용에서 오류를 확인하고 **상태 다시 확인**을 누를 수 있습니다. 서버를 종료하면 이 서버가 시작한 이미지 준비 작업도 중지됩니다. 기존 설치의 서버가 계속 실행 중이라면 종료하고 `python3 server.py`로 다시 시작하세요.

필요하면 프로젝트 폴더의 별도 터미널에서 직접 빌드할 수 있습니다.

```bash
docker build -f Dockerfile.cpp -t badak-cpp:13.5.0 .
docker build -t badak-torch:2.8.0 .
```

## 다른 사람에게 링크를 보내면 열리나요?

아니요. `127.0.0.1`은 주소를 연 사람 자신의 컴퓨터를 뜻합니다. 각자 저장소를 내려받아 서버를 실행해야 합니다. 다중 사용자에게 공개하려면 별도의 안전한 배포와 실행 환경이 필요합니다.

# 학습 확장 계획

이 문서는 앞으로 만들 수업의 계획입니다. 아래 항목은 아직 사이트에서 실행할 수 있는 수업이 아닙니다. 현재 수업은 [전체 학습 목차](../CURRICULUM.md)를 확인하세요.

## 기초와 자료구조

- Python: 문자열·불리언·오류 읽기·입력 검증 입문 다음으로 모듈, 파일 처리와 테스트를 보강합니다.
- C++: 현재 템플릿, concepts, 스마트 포인터, 예외 처리와 비소유 뷰의 입문 수업이 있습니다. 앞으로 템플릿 응용, 이동의 세부 규칙, 예외 안전성 보장, 범위·뷰 무효화와 테스트를 더 깊이 다룹니다.
- 자료구조: 배열의 삽입·삭제, 트리와 그래프를 다룹니다. Python과 C++ 구현을 개념과 연결합니다.
- 알고리즘: 선택·삽입 정렬의 실행 기록, 그래프 순회와 비교 횟수 측정을 추가합니다.

## 미분과 신경망

현재 수동 역전파와 더하기·곱하기를 지원하는 작은 자동 미분기 수업이 있습니다. 텐서로 만든 뉴런 하나와 학습·평가 데이터 분리 수업도 있습니다. 앞으로 수치 미분과 PyTorch 결과 비교, 여러 뉴런과 활성화 함수, 다양한 데이터셋 평가로 확장합니다.

## Attention과 Transformer

1. 벡터 내적과 행렬 곱으로 토큰 사이의 유사도를 계산합니다.
2. softmax를 직접 작성해 점수를 가중치로 바꿉니다. 합이 1인지, 큰 값에서 수치적으로 안정적인지 확인합니다.
3. 작은 Q·K·V 행렬을 사용해 `softmax(QKᵀ / √dₖ)V`를 단계별로 직접 계산하고 shape와 실제 결과를 살펴봅니다.
4. 미래 토큰을 볼 수 없도록 인과 마스크를 적용합니다.
5. 다중 헤드, 위치 정보, 잔차 연결을 하나씩 추가한 뒤 작은 Transformer 블록을 만듭니다.
6. 작은 텍스트 데이터로 학습·평가하고 PyTorch의 제공 구현과 비교합니다.

처음에는 작은 CPU 텐서와 실제 실행 결과를 사용합니다. 수식의 기호·코드의 행·행렬의 값을 연결하는 시각화는 각 수업의 실행 기록이 준비된 후 추가합니다. Attention과 Transformer 전체가 이미 구현된 것은 아닙니다.

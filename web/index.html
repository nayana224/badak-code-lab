실제 실행 기록
코드의 변화를 한 단계씩
입력 코드를 실제로 실행해 남긴 값입니다. 일반 출력만 있는 코드는 단계 그림을 만들지 않습니다.
코드는 실제 Python 또는 C++ 실행 환경에서 처리됩니다. 실습 확인은 학습을 돕는 간단한 검사이며, 완전한 채점 시스템은 아닙니다.


실행 환경
브라우저에서 실습 준비하기
Python과 NumPy는 브라우저에서 실행합니다. 처음에는 인터넷 연결이 필요합니다.
C++과 PyTorch는 이 컴퓨터의 Docker에서 CPU로 실행합니다. Docker 설치가 필요하며, 처음 준비할 때 이미지를 내려받아 시간이 걸릴 수 있습니다.
환경 확인 중…
준비 진행 내용 보기
직접 설정하기
Docker Desktop 또는 Docker Engine을 실행한 뒤 프로젝트 폴더에서 필요한 이미지를 준비할 수도 있습니다.
docker build -f Dockerfile.cpp -t badak-cpp:13.5.0 .
docker build -t badak-torch:2.8.0 .
진행 상황과 작성 코드는 이 브라우저에 저장됩니다. 서버는 이 컴퓨터에서만 실행됩니다.

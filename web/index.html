입력 코드를 실제로 실행해 남긴 값입니다. 일반 출력만 있는 코드는 단계 그림을 만들지 않습니다.

RUNTIME GUIDE
내 노트북에서 어디까지 실행할까요?
Python · NumPy
Pyodide로 브라우저 안에서 실행합니다. 최초 실행에 인터넷과 다운로드 시간이 필요합니다. 중지를 누르면 실행 환경을 새로 만듭니다.
PyTorch · CPU
로컬 서버가 매번 격리된 Docker 컨테이너에서 실제 PyTorch를 실행합니다. Docker와 이미지 준비가 필요합니다.
docker build -t badak-torch:2.8.0 .
python3 server.py
C++ · CPU
로컬 Docker에서 실제 C++20 코드를 컴파일하고 실행합니다. 네트워크·파일 접근이 제한된 환경이며 GPU는 필요하지 않습니다.
docker build -f Dockerfile.cpp -t badak-cpp:13.5.0 .
현재는 개인 로컬 실행 모드입니다. 클라우드 실행 서버나 GPU는 연결되어 있지 않습니다.
환경 확인 중…
매 실행은 새 변수 공간에서 시작합니다. 진행 상황과 작성 코드는 이 브라우저에 저장됩니다. 자세한 설치 방법은 프로젝트 README를 확인하세요.
